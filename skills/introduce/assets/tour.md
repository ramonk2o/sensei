**meditate → prepare → train ⇄ log → graduate** ↺ after a release, the next version starts again from `log` ("what's next?") or `meditate`.

| Skill | What it's for | How to call it |
|---|---|---|
| `meditate` | Plans a new plugin, or a change that isn't settled yet, and splits it into ready backlog issues | `/sensei:meditate`, or "help me plan a plugin for teachers" |
| `prepare` | Sets up a plugin repository for sensei: CLAUDE.md, settings, backlog, changelog | `/sensei:prepare` |
| `train` | Creates or changes a skill from a real case: plan, branch, checks, reviews, test, merge | "the deck skill did X, it should do Y" |
| `log` | Notes ideas, bugs and debt, says what's next, keeps CHANGELOG.md | "note this idea for the deck skill", "what's next?" |
| `graduate` | Releases a version: number, checks, tag, release zip | `/sensei:graduate` |
| `spar` | Evaluates one skill made elsewhere, with no setup, and says how to bring it into sensei | `/sensei:spar`, or "can sensei tell me if my skill is good?" |
| `introduce` | This tour, or what a term means | `/sensei:introduce`, or "what is a pull request?" |
